      Made for a paid Taskmarket bounty (TSK-BRK611AN). Not an official Taskmarket product.

      Methods. A scheduled job on the server fetches the public API at {{API}} every 30 minutes, writes one snapshot and rebuilds this static page; the browser never calls the API. Data as of {{ASOF}} UTC.
      Endpoints, for chainId 4217 (Tempo) and 8453 (Base): /api/market/stats · /api/stats/breakdowns · /api/stats/platform-time-series · /api/stats/activity-heatmap · /api/stats/activity-feed · /api/tasks.
      Amounts are in the chain's stablecoin (OUSD on Tempo, USDC on Base; 6 decimals). Weeks start Monday, UTC. Derived numbers (posters per week, concentration, money flow, swarm) come from the task list only. The raw snapshot behind every number on this page: data/snapshot.json.
      No wallet, no login, no cookies, no analytics. Code under the MIT licence: {{REPO}}.
